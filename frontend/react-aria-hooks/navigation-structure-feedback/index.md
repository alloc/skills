# Navigation, Structure, and Feedback

Read when: adding breadcrumbs, links, tabs, toolbars, landmarks, separators, progress, meters, toast regions, or structural feedback widgets.

Avoid when: Avoid these hooks for static semantic markup that native HTML already exposes correctly without custom interaction or state.

| API | Consider when |
| --- | --- |
| [useBreadcrumbItem](./use-breadcrumb-item.md) | Use `useBreadcrumbItem` for the breadcrumb item part of the `useBreadcrumbs` pattern. |
| [useBreadcrumbs](./use-breadcrumbs.md) | Provides the behavior and accessibility implementation for a breadcrumbs component. |
| [useLandmark](./use-landmark.md) | Provides landmark navigation in an application. |
| [useLink](./use-link.md) | Provides the behavior and accessibility implementation for a link component. |
| [useMeter](./use-meter.md) | Provides the accessibility implementation for a meter component. |
| [useProgressBar](./use-progress-bar.md) | Provides the accessibility implementation for a progress bar component. |
| [useSeparator](./use-separator.md) | Provides the accessibility implementation for a separator. |
| [useTabListState](./use-tab-list-state.md) | Provides state management for a Tabs component. |
| [useTabList](./use-tab-list.md) | Provides the behavior and accessibility implementation for a tab list. |
| [useTabPanel](./use-tab-panel.md) | Use `useTabPanel` for the tab panel part of the `useTabList` pattern. |
| [useTab](./use-tab.md) | Use `useTab` for the tab part of the `useTabList` pattern. |
| [useToastRegion](./use-toast-region.md) | Use `useToastRegion` for the toast region part of the `useToast` pattern. |
