# useMove

Source: https://react-aria.adobe.com/useMove

## Import

- Import: `import {useMove} from 'react-aria/useMove'`

## Signature

```ts
useMove(props: MoveEvents): MoveResult
```

## Use For

Use when a custom slider, color control, or draggable surface needs normalized move gestures across mouse, touch, and keyboard.

## Implementation Guidance

- Use for continuous move gestures such as custom sliders, splitters, or drag-like controls not covered by higher-level hooks.
