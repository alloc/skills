# useLongPress

Source: https://react-aria.adobe.com/useLongPress

## Import

- Import: `import {useLongPress} from 'react-aria/useLongPress'`

## Signature

```ts
useLongPress(props: LongPressProps): LongPressResult
```

## Use For

Use when an element needs an accessible long-press gesture across mouse, touch, keyboard, and screen readers.

## Implementation Guidance

- Use for explicit long-press gestures; always provide an alternate activation path for keyboard and pointer users.
