# Collections and Selection

Read when: rendering item collections, option lists, menus, selects, comboboxes, tables, grids, trees, tags, async data, disabled keys, keyboard collection navigation, or selection state.

Avoid when: Avoid these hooks for static lists with no custom keyboard navigation, item semantics, disabled-item handling, or selection state.
