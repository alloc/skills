# useLabel

Source: https://react-aria.adobe.com/useLabel

## Import

- Import: `import {useLabel} from 'react-aria/useLabel'`

## Signature

```ts
useLabel(props: LabelAriaProps): LabelAria
```

## Use For

Provides the accessibility implementation for labels and their associated elements. Labels provide context for user inputs.

## Implementation Guidance

- Use for custom label/control relationships when a higher-level field hook is not in use.
- Use Lingui for product-specific label text.
