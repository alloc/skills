# Date, Time, and Color

Read when: building date fields, calendars, time fields, date pickers, range calendars, color fields, color sliders, color wheels, color swatches, or color areas.

Avoid when: Avoid these hooks for plain text display, simple static dates, or color values that do not need custom keyboard, pointer, validation, or segmented editing behavior.
